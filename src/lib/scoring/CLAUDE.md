# src/lib/scoring

- `xp.ts`: Pure functions. `calculateXP(tier, qualityScore) → number` — base = tier × 10, multiplied by quality multiplier (5→1.5x, 4→1.0x, 3→0.75x, 2→0.25x, 1→0x, 0→0x). `calculateMcXp(tier, correct) → number` — MC-index path: 0 on wrong, else tier × basePerTier × `XP.mcCorrectMultiplier` (defaults to free-text q=4 equivalence). Both rounded to integer. `calculateBaselineXp(startingTier, gradings) → number` — a closed baseline's XP: each grading's `calculateXP` at the starting tier, summed. The scoping close (`scoreBaseline`) and the course XP repair (`recomputeCourseTotalXp`) both call it, so the award and the repair share one formula. TDD.
- `progression.ts`: Pure function. Tier advancement requires ≥80% of current tier concepts with last quality ≥3, AND minimum 5 assessed concepts. TDD.
- `verdictBand.ts`: Pure function `verdictForQualityScore(qualityScore) → verdict`, read from `VERDICT_QUALITY_BANDS` (`src/lib/types/jsonbBaseline.ts`). A free-text answer's `is_correct` is its score in the `correct` band (4-5), so correctness and XP share one score (issue #198). TDD.
- `startingTier.ts`: Pure function `determineStartingTier({ results, scopeTiers }) → tier` (issue #94). Walks the in-scope tiers from lowest to highest. A tier is mastered when its share of correct answers (quality 4-5, via `verdictForQualityScore`) is at least `BASELINE.tierMasteryRatio`. Returns the first tier not mastered, or the highest if all are. A tier with no answers is not mastered. Each result carries its question's tier, fixed at generation, never the model's `conceptTier`. TDD.
- `scoreBaseline.ts`: Pure function `scoreBaseline`. Merges LLM + mechanical baseline gradings into canonical order, places the learner with `determineStartingTier`, then computes total XP at that `startingTier` through `calculateBaselineXp`. Mechanical entries win the dedupe (LLM never grades MC). Throws on an out-of-scope `conceptTier` (defence-in-depth).
- These are deterministic. The LLM cannot influence XP, the starting tier, or tier advancement. This is the anti-gaming boundary.
